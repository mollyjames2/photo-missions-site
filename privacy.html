Privacy Policy

Photo Missions is a small private app, built for a handful of personal events run by its one developer. It is not offered to the public and does not sign up new users.

What it does with Google data

The app connects to one Google account chosen by its organiser, using the drive.file Google Drive scope — the narrowest Drive permission, which only ever lets the app see or write files it created itself, never any other file already in that Drive account. Guests' uploaded photos and videos are saved into that Drive account, inside a folder named for the event.

The app also stores small amounts of progress data (which tasks a device has completed, and optionally a guest's first name) in a private Google Firestore database, used only to run the game itself — never sold, shared, or used for advertising.

Who can see this data

Only the event's organiser, via their own Google Drive. Guests do not have accounts and cannot see other guests' data beyond what the app's own event pages intentionally show.

Revoking access

The connected Google account's access can be revoked at any time at myaccount.google.com/permissions.
